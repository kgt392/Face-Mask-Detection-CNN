# Face Mask Detection Using Convolutional Neural Networks (CNN)

![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)
![TensorFlow](https://img.shields.io/badge/TensorFlow-2.x-orange.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

An end-to-end deep learning project for binary image classification to determine whether a person is wearing a face mask or not. This project trains and benchmarks three Convolutional Neural Network (CNN) architectures (1-layer, 2-layer, and 3-layer CNNs) using stratified splits and macro-averaged evaluation metrics.

---

## 📌 Problem Statement

The goal of this project is to classify face images into two categories:
- **`with_mask`**: People wearing a face mask.
- **`without_mask`**: People not wearing a face mask.

We investigate how model depth affects performance and generalizability on held-out test data by comparing:
1. **CNN-1**: 1 Convolutional Layer (32 filters)
2. **CNN-2**: 2 Convolutional Layers (32, 64 filters)
3. **CNN-3**: 3 Convolutional Layers (32, 64, 128 filters)

## 🔬 Pipeline & Methodology

1. **Data Auditing & Cleaning**:
   - Lists file paths, sizes, extensions, and class labels.
   - Computes SHA-256 hashes to eliminate exact duplicate images.
   - Decodes images via TensorFlow to drop corrupt or unreadable files.
2. **Exploratory Data Analysis (EDA)**:
   - Visualizes class distribution bar plots.
   - Renders sample grids of masked and unmasked faces.
3. **Stratified Splitting**:
   - **70%** Training Set
   - **15%** Validation Set
   - **15%** Held-out Test Set
4. **Data Preprocessing & Pipeline**:
   - Images resized to standard input dimensions: **128 × 128 × 3**.
   - Normalized pixel intensity to **[0, 1]**.
   - Balanced class weights computed from training set labels to handle imbalance.
   - Accelerated data loading with `tf.data` API (`batch(32)`, `prefetch`, `AUTOTUNE`).
5. **CNN Architectures**:
   - Convolutional layers with $3 \times 3$ kernels and ReLU activation.
   - Max Pooling ($2 \times 2$) downsampling.
   - Dense hidden layer (64 units, ReLU) with Dropout (0.30) for regularization.
   - Sigmoid output neuron with Binary Cross-Entropy loss and Adam optimizer ($lr=0.001$).
   - Early stopping monitoring validation loss (`patience=3`).
6. **Model Evaluation**:
   - Accuracy, Macro-Precision, Macro-Recall, and Macro-F1.
   - Validation loss/accuracy learning curves.
   - Confusion matrix and full classification report.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/kgt392/Face-Mask-Detection-CNN.git
cd Face-Mask-Detection-CNN
```

### 2. Set Up Virtual Environment & Dependencies
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Running in Google Colab (Recommended)
1. Open [Google Colab](https://colab.research.google.com/).
2. Upload `Experiment12_Face_Mask_Detection_CNN.ipynb`.
3. Download the dataset from [Kaggle](https://www.kaggle.com/datasets/omkargurav/face-mask-dataset) and upload/extract it to `/content/face_mask_dataset/`.
4. Enable GPU: `Runtime > Change runtime type > T4 GPU`.
5. Run all cells in the notebook.

### 4. Running Locally
1. Launch Jupyter Notebook:
   ```bash
   jupyter notebook Experiment12_Face_Mask_Detection_CNN.ipynb
   ```
2. Update the `DATASET_DIR` variable to point to your local dataset folder.
3. Run the cells to train and evaluate the models.
